# Sistema visual · Procuraduría 104-2026 · 3PU-15

## Criterio

Las imágenes generadas funcionan como **apoyo pedagógico y editorial**. No sustituyen el contenido HTML de las lecciones, las citas normativas ni las fuentes oficiales. Cuando una pieza resume una ruta jurídica, el texto y las fuentes del módulo siguen siendo la referencia para estudiar detalles, excepciones y vigencia.

## Comportamiento en lecciones

Las piezas asociadas a lecciones usan `LessonSupportGraphic`, por lo que pueden abrirse en un visor ampliado con zoom sin abandonar la ruta de aprendizaje.

## Comportamiento en unidades

Las 17 unidades muestran una miniatura contextual en el encabezado. Algunas rutas comparten intencionalmente la misma pieza (por ejemplo, las tres unidades disciplinarias) para reforzar continuidad temática en vez de presentar ilustraciones distintas para conceptos que pertenecen a una misma secuencia.
